# Partner Rep Map (v1 — iPhone)

Personal map of partner sales reps. Sample data only.

## Locked decisions
- A **rep** is a partner AE / sales exec under one of your Salesloft accounts.
- **Champion** is only what you mark. Warm = last touch within 90 days. Cold = older.
- Accounts are **partners**. You can add more.
- Map is the US; cities and roads appear as you zoom.
- v1 starts on **iPhone**. PC and iPad layouts next.

## Use on iPhone
This cannot be opened as a raw file on the phone. It needs a URL.

Easiest options:
1. Drop the `partner-map` folder on any static host (GitHub Pages, Netlify drop, your homelab).
2. On a PC on the same Wi-Fi, from this folder run `python3 -m http.server 8080`, then on the phone open `http://YOUR-PC-IP:8080`.
3. In **Safari** (not Chrome): Share → **Add to Home Screen**. Leave Open as Web App on.

Data is stored in that phone’s browser (localStorage). Reset sample with the ↻ button.
